2. 全站共同的视觉语言

2.1 深色分层
- 首页、题目列表和个人主页的大面积页面底色取样为 #1A1A1A。
- 普通卡片、侧栏及面板常见深灰色，截图取样有 #262626、#282828；题目详情外侧工作区取样为 #0F0F0F，内容面板为 #262626。
- 不同层级主要靠深浅灰、窄间距、细分隔线和圆角区分；没有用大面积粗边框切割内容。
- 主文字接近白色，次级文字为中灰。蓝色突出链接和部分图标；绿色用于已解题、提交或成功语义；青绿、琥珀、红色分别标记 Easy、Med.、Hard。橙黄用于 Store、Premium、奖杯和积分相关入口。
- 彩色横幅、徽章、头像、热力图和小图标集中提供视觉焦点，正文区域仍保持克制的深色背景。

2.2 形状、排版、密度
- 常用控件是短圆角矩形或胶囊形：搜索框、分类筛选、难度标签、活动卡片、按钮、题目行和资料卡片均可见这种处理。
- 文本使用无衬线外观；代码、输入输出示例和约束中的表达式使用等宽外观。截图不能证明具体字体家族。
- 标题和关键数字较亮且更粗；元信息、时间、说明文和未选中的导航较淡。行间距允许列表快速扫描，卡片内部有比列表行更充足的留白。
- 内容排列以可快速扫描为目标：图标旁接短标签，标题在前，辅助信息靠后；长说明通过省略号或截断限制在当前行数内。
- 深色背景中仍能区分交互层级：当前标签高亮或有下划线，当前侧栏项有较亮的块状背景，普通链接用蓝色或亮色文字强调。

2.3 导航外壳
- 首页、题目列表、个人主页共用一条顶部导航：左侧 LeetCode 标识，其后依次可见 Problems、Contest、Discuss、Interview、Store；右侧有搜索、通知、火焰计数、头像与 Premium 入口。
- Interview 和 Store 后有向下箭头，表明存在下拉入口；截图未展示展开后的内容。
- 顶栏自身比页面底色稍亮，底部有细分界。题目列表页的 Problems 具有亮色下划线与较亮文字，显示当前导航状态。
- 首页和个人主页的主要内容居中，左右保留宽边距；题目列表页和详情工作区使用更宽的屏幕区域。
- 题目详情改用工作区顶栏：左侧是标识、Problem List、前后切换及随机图标；中央有运行图标与绿色 Submit；右侧是一排工具、通知、头像和 Premium。它不是其余三页的原样顶栏。

3. 图一：首页

3.1 页面骨架
- 顶栏下为居中的双栏内容：左侧是占主要宽度的信息流，右侧是较窄的深灰色功能栏；两栏之间有清晰的空隙。
- 左侧不把每条动态包进独立大卡片，而是让信息流直接坐落在深色页面上，用横向细线分隔条目。
- 右侧功能栏是连续的大面板，内部以横线分隔课程、比赛、讨论、商店和题型入口。

3.2 信息流条目
- 首条是奖杯图标、相对时间、比赛邀请与蓝色比赛链接。
- 后续条目左侧是站点标识或用户头像；右侧先放相对时间，再放发布者、动作文字与蓝色标题链接，然后是白色正文摘要。
- 摘要达到当前展示长度时出现省略号；条目之间保留足够的上下留白，使时间、标题和正文可一眼分层。
- 信息流同时容纳官方消息和社区讨论，头像、颜色与标题文本帮助区分来源。

3.3 右侧功能栏
- 顶部是紫色课程宣传横幅，有显眼的 Start Learning 按钮。
- 下面的 Contest 模块用奖杯插画、短说明和 Join Contest 按钮形成活动入口。
- Discuss Now 模块用绿色对话气泡插画、简短说明和 Let's Discuss 按钮形成社区入口。
- Shop with LeetCoins 模块用金币插画、说明和 Redeem 按钮形成商店入口。
- 再往下是带小图标的文本入口，如 OO Design、Operating System、Pick One、Algorithms、Database 和 Shell。
- 功能栏的彩色插画比正文醒目，但按钮仍采用较低饱和度的灰色或白色表面。

4. 图二：题目列表

4.1 三段式横向组织
- 顶栏下左侧是垂直导航栏，中间是题目发现与列表，右侧是日历及推荐信息栏；每一段都有明确的内容职能。
- 左栏从上到下可见 Library、Quest、Explore、Study Plan；Library 用较亮的深灰块显示当前状态。下方以分隔线划出 My Lists，并显示添加入口、Favorite 和锁图标。
- 中栏先展示一排高饱和度宣传横幅，再展示主题词及数量、题型筛选胶囊，最后进入搜索与题目行。
- 右栏顶部是每日签到日历和 Weekly Premium；其下是 Friends Check-in，再下是 Trending Companies 搜索框与公司标签。

4.2 发现区与筛选区
- 宣传横幅并排铺陈，分别使用深蓝、绿色、紫色和亮蓝色背景；各横幅承载独立标题或插画。截图只显示横排的一段，不能确定完整轮播行为。
- 横幅下有 Array、String、Hash Table、Math、Dynamic Programming 等主题词，后接小号数量徽标；末端可见 Expand。
- 下一行是 All Topics、Algorithms、Database、Shell、Concurrency、JavaScript、pandas 等胶囊入口，前面配小图标；All Topics 为白底深字，其他为深灰底浅字。
- 分隔线下方是 Search questions 输入框、排序圆形按钮、带红点的筛选按钮。右侧显示 solved 进度及随机切题图标。
- 顶栏 Search 与列表内部 Search questions 是两个不同位置、不同范围的搜索入口；截图无法确认具体搜索逻辑。

4.3 题目行
- 题目列表是密集的多行表格外观，隔行使用深灰色圆角背景，另一行贴近页面底色；这种交替明暗帮助横向扫读。
- 标题列靠左，前面带题号；右侧依次可见通过率、难度和灰色锁定或权限图标。部分行还出现蓝色小日历标记。
- Easy 用青绿色，Med. 用橙黄色，Hard 用红色；通过率是次级灰色文字。题名比同一行中的数值和图标更亮。
- 列表从 Two Sum、Add Two Numbers 等题目开始，但最上方另有一条带日历图标的题目行；应按不同内容类型呈现，不把当前截图的排序视为永久顺序。
- 右侧公司标签是灰色胶囊，名称后嵌入橙色数量块；其结构与题目难度标签不同。

5. 图三：题目详情与代码工作区

5.1 总体分区
- 该页使用全宽工作台布局，外侧近黑色背景形成面板缝隙；左边是题目说明，右边上部是代码编辑器，右边下部是测试区域。
- 左右主面板在截图中接近各占一半；右边编辑器与测试区又纵向分割。分隔处可见窄缝和小型把手外观。
- 三个内容区域各有自己的深灰标题栏，能同时阅读题意、编辑代码和查看测试结果。截图中可见内部滚动条；不能仅凭静态图确认拖动调整尺寸的行为。

5.2 左侧说明面板
- 标题栏依次有 Description、Editorial、Solutions、Submissions 等页签；Description 当前高亮，并带蓝色图标。
- 正文顶部以较大的“1. Two Sum”为标题。下一行是 Easy、Topics、Companies、Hint 胶囊，其中 Companies 带锁图标。
- 题意正文用白色段落文字，变量 nums、target 等以行内代码底色突出；重点语句以斜体或加粗形成语义层级。
- Example 1/2/3 各有小标题；输入、输出、解释使用缩进与细竖线围成代码式示例块。Constraints 以项目符号列表和行内等宽表达式呈现。
- 截图底部可见评价、评论、收藏、外链和帮助图标区；右下显示在线人数。截图未展示点击后的状态，也不能确认此区域是否固定定位。

5.3 右侧代码面板
- 最上层标题栏显示绿色代码图标与 Code。
- 次级工具条左侧是语言选择 C++、锁图标与 Auto；右侧排列若干编辑器工具图标。截图没有展开语言列表或工具菜单。
- 编辑区域为深灰底，左侧行号列，正文使用等宽字体及蓝、青、绿等语法着色；初始代码模板可见 class Solution 和 twoSum 函数。
- 面板底部左侧显示 Saved，右侧显示光标位置 Ln 1, Col 1；这些状态信息与编辑内容分离。
- 页面顶栏的运行图标和绿色 Submit 是代码操作的主要入口，颜色使提交动作在黑色顶栏上特别突出。

5.4 右侧测试面板
- 标题栏可见 Testcase 与 Test Result，后者在截图中亮起；正文区域显示“You must run your code first”的居中空状态。
- 测试区保持足够高度，与编辑器之间有显著的水平边界；空状态使用低对比度文字，不抢占代码和题意的注意力。

6. 图四：个人主页

6.1 总体布局
- 与首页共用居中的顶部导航和深色页面背景。主内容分左侧资料栏和右侧较宽的数据区域。
- 左侧资料栏主要由文字、分隔线和小型胶囊组织，不是整栏包在一张大卡片中；右侧各数据模块使用圆角深灰卡片。

6.2 左侧资料与能力信息
- 顶部把方形圆角头像放在姓名与账号文本旁；下方显示 Rank、Following、Followers。绿色 Edit Profile 按钮横向占据资料栏大部分宽度。
- Community Stats 逐项列出 Views、Solution、Discuss、Reputation，每项有彩色图标、数值和 Last week 子信息。
- Languages 按语言标签显示已解题数量；Skills 分 Advanced、Intermediate、Fundamental 三层，缺少数据时直接显示 Not enough data。
- 模块之间以细横线和垂直留白分隔；左栏栏目标题较亮，统计项和辅助说明逐级变淡。

6.3 右侧统计卡片
- 首行左卡以大号圆弧进度图展示 Solved 与 Attempting，总数放在中间；右侧用 Easy、Med.、Hard 三个竖排小块显示分难度数量，颜色与题目列表保持一致。
- 首行右卡是 Badges：顶部显示数量，卡片中下部显示徽章图案、Locked Badge 与徽章名称。
- 第二行是近一年 submissions 热力图：顶部显示提交次数、Total active days、Max streak 和 Current 下拉；中间是按周排布的细小方格，底部是月份缩写。少量有记录的格子使用绿色。
- 下方活动卡片有 Recent AC、List、Solutions、Discuss 标签及 View all submissions 入口；当前 Recent AC 高亮，下面显示一条题目记录与相对时间。
- 右下角另有悬浮的蓝色聊天图标按钮；截图不能确定其打开内容。
